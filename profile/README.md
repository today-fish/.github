# 오늘의 수산 🐟

### 오늘의 수산 시세를 더 쉽게, 가격 변화의 이유까지.

공공데이터와 AI 기반 시장 분석을 연결하는
수산물 가격 인사이트 서비스

**Seafood Price Intelligence Platform**

</div>

---

## 🌊 About

**오늘의 수산**은 수산물 가격이 얼마나 변했는지뿐 아니라,
왜 변했는지 이해할 수 있도록 돕는 서비스입니다.

공공 수산물 가격 데이터, 시장 보고서, 최신 이슈를
연결해 소비자에게 유용한 정보를 전달합니다.

## ✨ Key Features

| 기능 | 설명 |
|---|---|
| 📈 Price Chart | 산지·도매가격의 기간별 변화 |
| 🧠 AI Price Insight | 가격 변동과 시장 요인에 대한 근거 기반 설명 |
| 📰 Market Issues | 수산물 관련 시장 동향과 주요 이슈 |
| 💬 Community | 어종별 실시간 채팅 |
